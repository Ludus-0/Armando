# English Grammar Assessment

Static interactive test focused on Past Simple, Past Participle and Present Perfect. Includes 88 multiple-choice questions, a reading passage, browser text-to-speech listening, final scoring, Spanish explanations for incorrect answers, and a restart button. No backend, API keys, build tools, or paid dependencies are required.

## Run locally

Open `index.html` in a modern browser. Internet access is not required; listening uses the browser's built-in speech synthesis where available.

## Publish with GitHub Pages

1. Create a GitHub repository.
2. Upload `index.html` and `README.md` to the repository root (not inside another folder).
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.
6. Wait for the deployment link to appear in the Pages section.

All project resources use relative paths; there are no external assets. The listening audio is generated locally by the browser's Speech Synthesis API.
